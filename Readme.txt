# 🍔 Swiggy Sales Analysis Dashboard

An interactive Sales Analysis Dashboard built in Microsoft Excel to analyze Swiggy sales performance across different states, cities, food categories, and time periods.

---

## 📌 Project Overview

This project focuses on analyzing Swiggy sales data using Microsoft Excel. The dashboard provides business insights through KPIs, Pivot Tables, Charts, Slicers, and Maps, enabling users to monitor sales trends and make data-driven decisions.

---

## 🎯 Business Objectives

- Analyze overall sales performance
- Monitor monthly, weekly, and daily sales trends
- Compare sales across different Indian states
- Identify top-performing cities
- Analyze Veg vs Non-Veg sales
- Track customer ratings and order volume
- Provide interactive filtering using slicers

---

## 📈 Dashboard Features

- Monthly Sales Trend
- Weekly Sales Trend
- Daily Sales Trend
- Sales by Food Type (Veg vs Non-Veg)

- Top 5 Cities by Sales
- Quarterly Sales, Ratings & Orders Summary

  - Restaurant Name
